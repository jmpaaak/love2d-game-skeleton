# UI contract (anti-slop)

Load Hermes skill `anti-slop-ui` before HUD or menu work.

- One primary action per screen. No extra chrome.
- Distinctive type/color/shape for *this* game. Ban Inter + purple gradient + rounded-card defaults.
- Waiting/loading copy ends without `...` ASCII ellipsis. Use a static word (`대기`) when motion is reduced.
- Keyboard and pointer both reach every action. Hit targets stay readable at nearest-neighbor scale.
- Errors say the next step. Korean UI uses `~에요`.
- Do not copy another product's look.
