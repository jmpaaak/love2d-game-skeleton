# LÖVE2D Game Skeleton repository guidance

- Treat `docs/MODULE_STRUCTURE.md` as the structure source of truth.
- Read only the relevant pending item from `docs/feedback/INBOX.md` before implementation. Do not read the whole inbox.
- Add tests before implementation and commit only verified changes.
- Do not store credentials in the repository.
- Load `karpathy-guidelines` before writing, reviewing, or refactoring code.
- Load `verification-before-completion` and use that command output before claiming done, tests pass, or a commit/PR is ready.
- Do not vendor Oxlint `install-anti-slop` into this Lua tree.
- Reply styles `attention-kind` / `spartan` / `rundown` apply only when the user asks.
